# 版本更新说明

V2.0：2026-09-17

- 新增「账号与同步」模块：用邮箱注册/登录后，手机与电脑共用同一份学习记录
- 同步内容：词条学习状态（已掌握/待复习/收藏/学习时间）、用户设置、今日学习会话
- 采用本地优先架构：IndexedDB 仍是唯一数据真相源，断网、未登录时行为与以前完全一致
- 冲突按客户端时间戳解决（较晚的一次操作生效）；「清除记录」会广播给所有设备
- 未配置 Supabase 时功能自动隐藏，不影响原有使用方式
- 详细设计与部署步骤见 `docs/supabase-sync.md`
